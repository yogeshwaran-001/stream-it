# ServiceNow Laptop Procurement Automation

An automated workflow built in ServiceNow to streamline the employee laptop procurement process. This project reduces manual effort, speeds up approvals, and integrates seamlessly with inventory systems.

## 🚀 Features
* **Service Catalog Item:** User-friendly portal form for requesting hardware.
* **Flow Designer Workflow:** Fully automated flow handling approvals and order processing.
* **Dynamic Scripting:** JavaScript-based logic for business rules and validations.

## 📂 Project Structure
* `docs/`: Technical documentation and architecture diagrams.
* `flow-designer/`: Step-by-step breakdown of the ServiceNow Flow.
* `scripts/`: Client-side and server-side JavaScript code.
* `screenshots/`: Visual previews of the ServiceNow instance setup.

## 🛠️ Setup Instructions
1. Import the Update Set or Studio Application (if applicable).
2. Configure the user groups for **Managers** and **Procurement Teams**.
3. Activate the Flow Designer workflow `Laptop Order Flow`.
